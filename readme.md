# CLBuddy/Command Line Buddy
A simple script that acts as a simple command line pet. You can use a handful of commands, and you can interact with it and mess around.

- ```!help``` prints all commands of the tool, except for one 👀👀👀👀👀 oh boy i sure do love Touhou...
- ```!greet``` greets the user.
- ```!emoticon``` prints an emoticon after a little more inquiry.
    - ```!help``` this subcommand prints all the emoticons you can use.
- ```!touhou``` not listed in the !help command, a little easter egg that prints ASCII art of Reimu from Touhou.

## Getting Started

### Dependencies

None needed, just make sure your OS can run EXE files.

### Installing

Download the script (main.exe) from [Releases](https://github.com/khalidthekman/command-line-buddy/releases/tag/v.01)

### Executing program
> For !touhou and epic_face subcommand in !emoticon,
> The images for them are broken because I couldn't make a standalone binary with the images attached. Everything else works as intended.
Double click the file after downloading.
